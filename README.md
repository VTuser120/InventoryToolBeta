HOW TO USE THE TOOL

Upload Data: Click the ↑ UPLOAD FILE button at the top right corner. You can import an AS400 export formatted as either an .xlsx workbook or a .csv file.

Configure Parameters: Adjust the sidebar values to target specific metrics (e.g., select your desired Warehouse code, modify threshold caps, or toggle Cost Center exclusions).

Process Analysis: Click the ▶ RUN ANALYSIS button to map your data splits dynamically.

Review and Export: Click through any analysis tab to view categorized rows. Use ↓ EXPORT CSV to grab individual reports.
