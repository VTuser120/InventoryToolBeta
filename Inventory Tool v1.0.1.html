How to Use the Tool

  1. Upload Data: Click the ↑ UPLOAD FILE button at the top right corner. You can import an AS400 export formatted as either an .xlsx workbook or a .csv file.
  2. Configure Parameters: Adjust the sidebar values to target specific metrics (e.g., select your desired Warehouse code, modify threshold caps, or toggle Cost Center exclusions).
  3. Process Analysis: Click the ▶ RUN ANALYSIS button to map your data splits dynamically.
  4. Review and Export: Click through any analysis tab to view categorized rows. Use ↓ EXPORT XLSX to grab individual reports.

Tab Rules & Filters

  • Consolidation: Identifies matching Item & Serial sets sitting across multiple warehouse storage bins whose individual On-Hand values rest at or below your set Pallet Threshold.
  • Under SF Threshold: Spots unallocated isolated profiles with On-Hand balances resting lower than your custom threshold limit (Default: 30 SF) for potential rapid bin write-offs.
